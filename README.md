# AI-project-univ

교내 경진대회 제출용 프로젝트입니다. 현재 화면은 카카오맵에서 위치를 선택하고 주소를 검색하는 단계까지 구현합니다.

## 파일별 역할
- `data/geojson/HangJeongDong_ver20261001.geojson`: 2026년 10월 기준 전국 행정동 경계 원본
- `data/geojson/anyang-si.geojson`: 위 원본에서 안양시 만안구·동안구 행정동 31개를 추출한 경계
- `config.js`: 카카오맵 api 키를 저장해둔 js 파일(gitignore 설정으로 인해 커밋 안됨)


## 실행 방법

1. 카카오디벨로퍼스에서 앱을 만들고 **JavaScript 키**를 확인합니다.
2. `config.example.js`를 복사해 `config.js`를 만들고 `YOUR_KAKAO_JAVASCRIPT_KEY`를 발급받은 JavaScript 키로 바꿉니다. `config.js`와 `.csv`는 Git에 포함되지 않습니다.
3. 프로젝트 루트에서 정적 웹 서버를 실행합니다. 예: `python3 -m http.server 8000`
4. 브라우저에서 `http://localhost:8000`을 엽니다.

`file://`로 직접 열지 말고 HTTP 주소로 실행해야 합니다. 배포할 때는 `config.js`를 배포 환경에 따로 제공하고 저장소에는 커밋하지 마세요. 브라우저에서 쓰는 JavaScript 키는 페이지에 전달되므로 비밀값이 아닙니다. 카카오디벨로퍼스에서 허용 도메인을 등록해 사용처를 제한하세요.

## 구현 범위와 데이터 한계

- 지도 클릭으로 마커를 옮기고 좌표 및 역지오코딩 주소를 표시합니다.
- 주소 검색 성공 시 지도 이동과 마커 표시를 지원하며, 검색 결과 없음과 SDK/주소 요청 오류를 안내합니다.
- `data/geojson/anyang-si.geojson`의 2026년 10월 기준 행정동 경계로 안양시 안에서만 지도 클릭과 주소 검색 위치를 선택합니다.
- 이 연결은 이름 기반입니다. 정확한 상권 ID가 하나로 확인되지 않는 후보는 사용자에게 구분해 표시합니다.
- 매출 예측, 머신러닝, 비교 목록 및 그래프는 이 단계에 포함하지 않습니다.
