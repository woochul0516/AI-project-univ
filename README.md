# AI-project-univ

교내 경진대회 제출용 프로젝트입니다. 현재 화면은 카카오맵에서 위치를 선택하고 주소를 검색하는 단계까지 구현합니다.

## 실행 방법

1. 카카오디벨로퍼스에서 앱을 만들고 **JavaScript 키**를 확인합니다.
2. `config.example.js`를 복사해 `config.js`를 만들고 `YOUR_KAKAO_JAVASCRIPT_KEY`를 발급받은 JavaScript 키로 바꿉니다. `config.js`는 Git에 포함되지 않습니다.
3. 프로젝트 루트에서 정적 웹 서버를 실행합니다. 예: `python3 -m http.server 8000`
4. 브라우저에서 `http://localhost:8000`을 엽니다.

`file://`로 직접 열지 말고 HTTP 주소로 실행해야 합니다. 배포할 때는 `config.js`를 배포 환경에 따로 제공하고 저장소에는 커밋하지 마세요. 브라우저에서 쓰는 JavaScript 키는 페이지에 전달되므로 비밀값이 아닙니다. 카카오디벨로퍼스에서 허용 도메인을 등록해 사용처를 제한하세요.

## 카카오 개발자 콘솔 설정

카카오디벨로퍼스 앱 관리 화면에서 **앱 > 플랫폼 키 > JavaScript 키 > JavaScript SDK 도메인**에 개발 및 배포 주소를 등록합니다. 로컬 실행 주소는 `http://localhost:8000`, 배포 주소는 실제 서비스 도메인을 입력합니다. 포트와 프로토콜이 다른 주소를 사용할 경우 각각 등록하세요. 지도 JavaScript API와 주소 검색(services 라이브러리)을 사용 설정해야 합니다.

도메인 등록 위치는 [카카오 JavaScript SDK 시작하기](https://developers.kakao.com/docs/ko/javascript/getting-started) 문서를 참고하세요.

## 구현 범위와 데이터 한계

- 지도 클릭으로 마커를 옮기고 좌표 및 역지오코딩 주소를 표시합니다.
- 주소 검색 성공 시 지도 이동과 마커 표시를 지원하며, 검색 결과 없음과 SDK/주소 요청 오류를 안내합니다.
- `data/geojson/anyang-si.geojson`의 행정동 경계로 안양시 안에서만 지도 클릭과 주소 검색 위치를 선택합니다.
- `골목상권현황.csv`, `발달상권현황.csv`의 `다중지역정보` 다각형을 안양시 경계와 교차하는 상권 경계로 변환해 `data/geojson/anyang-commercial-areas.geojson`에 저장했습니다. 위치가 다각형 안에 있으면 상권명과 매출 데이터의 상권 ID를 표시합니다. 매출 CSV와는 상권명으로 연결했습니다. 안양시와 교차하는 87개 경계 중 72개는 해당 이름이 매출 데이터에서 하나의 ID에만 연결됩니다. 나머지 15개 경계는 같은 이름에 여러 ID가 있어 후보 ID를 표시하고 하나로 단정하지 않습니다.
- 이 연결은 이름 기반입니다. 정확한 상권 ID가 하나로 확인되지 않는 후보는 사용자에게 구분해 표시합니다.
- 매출 예측, 머신러닝, 비교 목록 및 그래프는 이 단계에 포함하지 않습니다.

## 검증

프로젝트에 기존 프레임워크, 패키지 스크립트, 테스트나 린트 설정이 없어 별도 의존성 없이 정적 파일로 구현했습니다. 실행 후 브라우저에서 지도 키와 등록 도메인을 설정해 동작을 확인할 수 있습니다.
